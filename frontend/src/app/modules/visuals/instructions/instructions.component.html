📘 Instrucciones de uso

Bienvenido a CardStudio. En esta guía aprenderás cómo puedes materializar de manera fácil y sencilla tu TCG de ensueño.

🧩 1. Qué es una plantilla

{{isAccordionOpen(0) ? '−' : '+'}}

Las plantillas son los diseños base que determinan cómo se verán todas tus cartas. Controlan la disposición de imágenes, texto y elementos gráficos.

🛠️ ¿Cómo crear una plantilla?

Esta aplicación te permite crear plantillas usando la pestaña Editor. Puedes ir a esta pestaña desde la barra de navegación o clicando en Añadir Platilla en el Gestor de Cartas.

Aquí podrás modificar tu plantilla a tu gusto. Añade elementos y modifícalos como quieras.

Guarda tu plantilla cuando hayas terminado:

  • Para nuevas plantillas: Introduce un nombre descriptivo
  • Para modificaciones: Elige si mantener el nombre actual o cambiarlo

Consejos importantes

  • ✅ Cuando cambies algún parámetro de un elemento pulsa intro para confirmar el cambio
  • 📏 Mantén la misma estructura en todas las filas.
  • 🗂️ Puedes subir múltiples CSVs para diferentes tipos de cartas.
  • 📂 Usa nombres significativos al guardar tu CSV para reconocerlo facilmente.
  • 🔄 Puedes actualizar tu CSV en cualquier momento.

📄 2. Qué es un CSV

{{isAccordionOpen(1) ? '−' : '+'}}

Un CSV (por sus siglas en inglés Comma Separated Values) es un archivo de texto simple que organiza datos en forma de tabla, donde cada línea representa una fila y los valores están separados por comas. Es una manera de exportación de hojas de cálculo

¿Por qué necesito un CSV?

El archivo CSV se usa para generar tus cartas. En este archivo podrás escribir todos los datos relevantes como nombres, estadísticas, descripciones... de manera estructurada.

¿Cómo preparar mi CSV?

Puedes crear tu archivo CSV usando programas como Excel, Google Sheets o cualquier editor de texto:

  • La primera fila debe contener los encabezados (ej: nombre, poder, descripcion)
  • Cada fila siguiente representa una carta diferente
  • Guarda el archivo con formato CSV (UTF-8 recomendado)

¿Cómo subir mi CSV?

Desde la sección Gestor de Cartas en la barra de navegación:

  1. Haz clic en "Añadir un nuevo CSV"
  2. Selecciona tu archivo desde tu computadora
  3. Confirma la operación

Una vez subido, podrás ver una previsualización de tus datos y asignarles un nombre.

Consejos importantes

  • ✅ Usa nombres consistentes para los encabezados (los usarás al diseñar la plantilla)
  • 📏 Mantén la misma estructura en todas las filas.
  • 🗂️ Puedes subir múltiples CSVs para diferentes tipos de cartas.
  • 📂 Usa nombres significativos al guardar tu CSV para reconocerlo facilmente.
  • 🔄 Puedes actualizar tu CSV en cualquier momento.

🔗 3. Asignar CSV a Plantilla

{{isAccordionOpen(2) ? '−' : '+'}}

En el Gestor de Cartas encontrarás dos secciones importantes:

  • Plantillas: Tus diseños de cartas creados
  • Archivos CSV: Los conjuntos de datos que subiste

Cómo asignar un CSV a tu plantilla

  1. Selecciona una plantilla de tu lista
  2. Elige el archivo CSV que contiene tus datos
  3. Haz clic en el botón "Asignar CSV" que aparece junto a la plantilla

¿Qué logras al asignar un CSV?

Al vincularlos:

  • 📌 Los datos del CSV automáticamente rellenarán los campos de la plantilla
  • 🖼️ Cada fila del CSV generará una carta única con el mismo diseño

Nota: Puedes asignar el mismo CSV a diferentes plantillas para crear variantes de tus cartas!

🖨️ 4. Generar Mazos de Cartas

{{isAccordionOpen(3) ? '−' : '+'}}

🎉 ¡Es hora de dar vida a tus cartas! Sigue estos pasos:

📌 Pasos para generar tus cartas

  1. Selecciona la plantilla con CSV asignado en el Gestor de Cartas
  2. Haz clic en el botón "Generar Mazo"
  3. Sube una carpeta con las imágenes que quieras para tus cartas
  4. Elige si quieres un zip con todas las imágenes en formato PNG o un PDF con las imagenes listas para imprimir

🔍 Qué ocurre al generar

  • Cada fila de tu CSV se convierte en una carta única.
  • Las imágenes de la carpeta y textos del CSV se asignan a las cartas si el nombre de los campos coinciden con la cabecera del CSV.
  • Se genera el ZIP o el PDF.

💡 Consejos profesionales

  • ✅ Revisa siempre una carta de prueba antes de generar el mazo completo
  • 📏 Verifica que todo el texto se muestra correctamente en los campos designados
  • 🔄 Puedes regenerar el mazo cuantas veces necesites si actualizas tu CSV o plantilla

Recordatorio: en el caso de que una cabecera del CSV y el nombre de un elemento de imagen coincidan, la aplicación buscará en la carpeta que subiste una imagen con el nombre que pusiste en el campo del CSV. Es por eso que es muy importante que las imágenes que subes y los campos del CSV tengan el mismo nombre. NO NECESITAS INCLUIR LA EXTENSIÓN!!
