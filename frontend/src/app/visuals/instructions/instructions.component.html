📘 Instrucciones de uso

Bienvenido CardStudio. En esta guía aprenderás cómo puedes materializar de manera fácil y sencilla tu TCG de ensueño.

Desde la sección Gestor de mazo podrás gestionar tus plantillas y datos de cartas

🧩 1. Crear una plantilla

Esta aplicación te permite crear plantillas que sirven de base para generar las cartas.

📄 2. Subir un CSV

Desde la sección CSV Datasets, añade un archivo CSV que contenga los datos de tus cartas.

🔗 3. Asignar CSV a Plantilla

Selecciona una plantilla y haz clic en "Asignar CSV". Esto vincula los datos con el diseño visual.

🖨️ 4. Generar Mazos

Una vez asignado, puedes hacer clic en "Generar" para crear las cartas.

📝 Consejos

  • ✅ Usa un CSV con encabezados claros (ej. nombre, poder, etc.)
  • 💾 Guarda tus plantillas regularmente
  • 🔁 Puedes volver y editar todo en cualquier momento
